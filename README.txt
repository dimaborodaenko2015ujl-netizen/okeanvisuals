Okean Visuals 1.21.4 - build project

Requirements:
- Java/JDK 21
- Internet connection (Gradle and Minecraft/Fabric dependencies are downloaded during the first build)

Build:
1. Open this folder.
2. Double-click build_mod.bat, OR open PowerShell here and run:
   .\gradlew.bat build
3. The finished JAR will be in:
   build\libs\

Note:
The launcher included here downloads the official Gradle 8.10.2 distribution on first use.
